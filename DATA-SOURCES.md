# Sources, datasets, and calculation conventions

The original V4 scientist records and source library are retained. V5 adds validated metadata for all 71 unique scientists and eight laboratories in `src/v5-core.js`. Related-scientist catalog entries indicate a shared topic; they do not establish historical influence.

## Empirical dataset

**Iris**: Fisher, R. A. (1936), UCI Machine Learning Repository, DOI [10.24432/C56C76](https://doi.org/10.24432/C56C76), [dataset record](https://archive.ics.uci.edu/dataset/53/iris), licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The local `src/data/iris.csv` is the repository's original `iris.data` variant, downloaded for this project. `src/data/datasets.js` serializes those same 150 records with an integer row ID and shorter class labels. The four measurements are in centimetres. UCI documents discrepancies in observations 35 and 38 relative to Fisher's publication; this app retains the downloaded original variant rather than silently changing those records. The benchmark contains three balanced classes and no missing features; it is not representative of all flowers or a deployment population.

The second classification dataset is synthetic, generated by project code from seeded Gaussian features and a noisy linear label rule. It contains no personal information. Synthetic examples and original project-generated illustrations can be reused under CC0; this does not change the licenses of original portraits, UCI data, runtime software, or cited publications.

## Laboratory evidence

| Laboratory | Data status and reference |
| --- | --- |
| John Snow | An explicitly labelled approximate Soho street schematic and synthetic household counts in arbitrary drawing units. No authentic death coordinates are claimed. Historical reading: [Snow's 1855 original work](https://www.gutenberg.org/ebooks/72894), [CDC historical account](https://www.cdc.gov/mmwr/preview/mmwrhtml/mm5334a1.htm). |
| Florence Nightingale | Six invented monthly mortality tables, not Crimean War data. Primary context: [1858 Notes, Wellcome Collection](https://wellcomecollection.org/works/jxwtskzc). Equal-angle polar sector and ring areas are proportional to counts; radius scales with the square root of cumulative counts. |
| Thomas Bayes | A modern mathematical screening example; expected counts can be fractional. Historical text: [Bayes's 1763 essay](https://doi.org/10.1098/rstl.1763.0053). Zero-probability evidence makes the posterior undefined. |
| Alan Turing | Three small mathematical tape programs, not a reconstruction of a historical machine. [Original 1936–37 paper](https://doi.org/10.1112/plms/s2-42.1.230). `_` represents a blank; the head, state, transition table, and last applied transition are shown. |
| Claude Shannon | Seeded synthetic bits and a mathematical binary distribution. [1948 original paper](https://doi.org/10.1002/j.1538-7305.1948.tb01338.x). Entropy is in bits, with zero-probability terms contributing zero. The binary symbol illustration is not an implemented optimal compressor. |
| John Tukey | Editable synthetic observations. Quartiles use linear interpolation at `(n−1)p`, also called type 7; sample standard deviation uses `n−1` and is undefined below two observations. Values beyond Q1−1.5 IQR and Q3+1.5 IQR are flagged for investigation. The box spans Q1–Q3; its horizontal line shows the full observed range, explicitly labelled, with flags separately marked. Reference: Tukey, *Exploratory Data Analysis*, Addison-Wesley, 1977, ISBN 0-201-07616-0; [NIST EDA handbook](https://www.itl.nist.gov/div898/handbook/eda/eda.htm). |
| W. Edwards Deming | Seeded synthetic measurements. A 20-observation baseline fixes individuals-chart limits at mean ± 3×average moving range/1.128, following the [NIST method](https://www.itl.nist.gov/div898/handbook/pmc/section3/pmc322.htm). Later observations do not redefine the limits. This model assumes a stable baseline and approximately independent measurements; an extreme point prompts investigation rather than proving a cause. Historical context: [Deming Institute](https://deming.org/explore/fourteen-points/). |
| Judea Pearl | Three specified toy structural causal models: confounder, mediator, collider. Observational and interventional probabilities are calculated from the displayed assumptions. [Pearl's overview](https://ftp.cs.ucla.edu/pub/stat_ser/r350.pdf). |

## Fitted classification models

All predictions are calculated locally. Splits are seeded, shuffled within each class, and stratified; each class retains training and testing records. Neighbors and multinomial logistic regression standardize features with training means and population standard deviations only, using scale 1 for constant features. The decision tree uses Gini impurity and a maximum depth capped at 8. Logistic regression uses 300 batch-gradient steps, learning rate 0.15, and L2 coefficient 0.001 excluding the intercept. These are readable teaching implementations, not substitutes for a production ML library.

Accuracy is the proportion correct. Per-class precision, recall, and F1 are calculated from the displayed confusion matrix. Macro metrics average classes equally and are labelled undefined if a component denominator is zero. F1 is computed as `2TP/(actual positives + predicted positives)`, so it is zero, rather than undefined, when errors exist but TP is zero. Repeated test-set parameter selection compromises the independence of a final evaluation; the interface explains the need for validation and a fresh final test set.

## References and images

The network includes a documented Buolamwini–Gebru collaboration with the [original Gender Shades paper](https://proceedings.mlr.press/v81/buolamwini18a.html). Other network edges are labelled methodological, shared-topic, or modern conceptual mappings. The historical-influence filter explicitly reports when no sourced edges are catalogued.

Portraits remain optional external Wikimedia lookups. Their original file records carry creator and license information. They are not AI-generated and no universal license is claimed. The source-linked story reader includes text alternatives and bibliographic landmarks; access to some original publications may require a publisher or library.

Python uses the pinned [Pyodide 314.0.7 runtime](https://pyodide.org/en/stable/usage/webworker.html), loaded from its versioned CDN path in a module worker. No optional Python packages are automatically installed. Pyodide and its included dependencies retain their upstream licenses.

`docs/link-report.json` records actual HTTP outcomes, access blocks, timeouts, and network failures. Successful automated access is not a guarantee of source quality or future availability.
